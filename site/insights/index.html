Insights

Every number on this page comes from one archive: a scheduled job records the repository's traffic, stars, forks, contributors and releases once a day and commits them to a public data branch. The page reads a single bundle built from that archive at deploy time. Nothing is estimated, and nothing is fetched from anywhere but this site.

at-a-glance

At a glance

Stars, forks, watchers, views and clones since collection began, contributors and total release downloads — each with a 30-day delta. A delta appears only when the archive covers the window it describes; otherwise it reads as a dash, and a figure that could only be assembled from a different span is labelled with the span it actually covers.

reach

Reach

Page views and repository clones with their unique-visitor counts. A gap in a line means that day was never measured, not that it fell to zero.

growth

Growth

Star and fork history with release tags marked on the time axis, so a jump can be read against what shipped. Both are point-in-time totals, so an unmeasured day is a break in the line rather than a drop.

where-people-come-from

Where people come from

Referring sites, ranked. GitHub reports these only as a trailing 14-day aggregate, so every figure here covers the two weeks up to its snapshot date — there is no daily resolution to be had.
